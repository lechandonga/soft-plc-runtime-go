# 控制程序格式

程序为纯文本行式指令表（IL），仅使用本地文件加载，不依赖任何外部服务。

## 词法规则

- 一行一条语句；`//` 之后直到行尾为注释；空行被忽略。
- 标签独占一行，形如 `loop:`；标签名为字母/下划线开头，后接字母数字下划线。
- 指令与操作数大小写：指令名大小写不敏感，地址区域前缀大写。
- 整个文件必须**有且仅有一个** `END`，且它是最后一条语句；`END` 之后出现任何语句都按结构错误拒绝。

## 地址

| 区域 | 位 | 字（有符号，小端） |
| --- | --- | --- |
| 输入 `I`（只读） | `I字节.位`，如 `I0.0` | `IB0`(8位) `IW0`(16位) `ID0`(32位) `IL0`(64位) |
| 输出 `Q` | `Q0.0` | `QB0` `QW0` `QD0` `QL0` |
| 位存储 `M` | `M0.0` | `MB0` `MW0` `MD0` `ML0` |
| 定时器 `T` | `Tn.Q`（到点位） | `Tn.PT`（预设毫秒）、`Tn.ET`（累计毫秒） |
| 计数器 `C` | `Cn.Q`（完成位） | `Cn.PV`（预设值）、`Cn.CV`（当前值） |

- 位编号范围 0..7；字地址必须按自身宽度对齐（如 `MW2` 合法，`MW1` 非法）。
- 立即数：十进制（`42`、`-7`）、十六进制 `16#FF`、二进制 `2#1010`。
- 比较符：`== != > < >= <=`。

## 指令集

| 指令 | 形式 | 语义 |
| --- | --- | --- |
| `LD` / `LDI` | `LD 位` | 结果位 `CR = 位` / `CR = !位` |
| `AND`/`ANI`/`OR`/`ORI` | `AND 位` | 对 CR 做与/与非/或/或非 |
| `OUT` | `OUT 位` | 目标位 = CR（仅 Q/M 可写） |
| `SET` | `SET 位` | CR 为真时目标位置 1（锁存） |
| `RST` | `RST 位|字|Cn` | CR 为真时目标清 0（计数器 CV/Q 归零） |
| `EU` / `ED` | 无操作数 | CR 上升沿/下降沿脉冲（边沿历史按指令位置绑定） |
| `MOV` | `MOV 字源 字目标` | 字传送（源可立即数，目标必须可写） |
| `CMP` | `CMP 比较符 字 字` | 比较结果写 CR |
| `JMP` | `JMP 标签` | CR 为真时跳转到标签 |
| `TON` | `TON Tn PT毫秒` | CR 为真时按每扫描周期 `ScanPeriodMS` 累计，ET≥PT 则 Q=1；CR 为假立即清零 |
| `CTU` | `CTU Cn PV 计数输入位 复位位` | 计数输入上升沿且未到 PV 时 CV+1；CV≥PV 时 Q=1；复位位为真时 CV=0、Q=0 |
| `END` | 无操作数 | 程序结束 |

说明：

- 定时器的时间基是配置项 `scan_period_ms`，与墙钟抖动解耦——相同输入序列与配置下逐周期结果完全可复现。
- `EU/ED` 的历史以“指令在程序中的序号”为键，程序结构变化即重新开始，不产生跨版本错位。
- 只支持条件 `JMP`（由当前 CR 决定），无返回值调用；向后跳转允许循环，受看门狗预算保护。

## 启动前校验（任一失败整体拒绝，绝不部分加载）

错误原因分类（`LoadError.Reason`）：

1. `Syntax`：词法错误、操作数数目不符、标签/比较符非法、PT 为负等。
2. `UnknownInstruction`：未知操作码。
3. `IllegalAddress`：地址格式、位号、对齐、只读区写入、非法保持项等。
4. `TypeError`：位/字类型用错（如 `LD MW0`、`MOV I0.0 MW0`）。
5. `UnknownLabel`：`JMP` 目标标签不存在。
6. `ReferenceError`：标签重复定义、保持项或安全输出引用了程序中不存在的地址。
7. `StructureError`：空程序、缺少/重复 `END`、`END` 后还有语句、配置非法。
8. `IllegalWriteTarget`：写入指令的目标落在运行时自己维护的状态量上（见下节）。

解析期不存在“静默按默认值顶替”：未在程序中出现的地址不会被自动创建为保持项。

## 写目标校验（`IllegalWriteTarget`）

凡是向目标写入的指令，目标必须落在真正可写的存储对象上，且对象种类要与指令匹配：

| 指令 | 合法目标 | 非法目标（`IllegalWriteTarget`） |
| --- | --- | --- |
| `OUT` / `SET` | `Q`/`M` 位 | 定时器/计数器字段（如 `T0.Q`、`C0.Q`） |
| `MOV` 目标 | `Q`/`M` 字 | 定时器/计数器字段（如 `T0.PT`、`T0.ET`、`C0.CV`、`C0.PV`） |
| `RST` | `Q`/`M` 位或字、整体计数器 `Cn` | 定时器（整体或字段）、计数器字段（如 `C0.CV`） |

定时器/计数器元件及其字段（`Tn.Q/PT/ET`、`Cn.Q/CV/PV`）由运行时自己维护，
只能由 `TON`/`CTU`/`RST Cn` 等指令内部更新，不允许作为普通写入目标。
只读输入区 `I` 与立即数作为目标仍按既有 `IllegalAddress`/`TypeError` 分类，行为不变。

这类判定全部在加载阶段完成、按 `IllegalWriteTarget` 分类整体拒绝（不允许部分加载）；
冷启动与热重载口径一致——热重载碰到这类程序同样整体拒绝，旧程序原样继续运行。
