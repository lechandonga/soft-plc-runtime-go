# 可配置项（本地 JSON）

示例：`testdata/programs/config.json`

| 字段 | 含义 | 默认 |
| --- | --- | --- |
| `scan_period_ms` | 扫描周期标称时长（毫秒），同时是定时器确定时间基，必须为正 | 10 |
| `watchdog_instructions` | 单周期指令条数预算，超限进入 `WatchdogFault` | 100000 |
| `watchdog_time_ms` | 单周期墙钟上限（毫秒）；从输入采样前起算，到输出提交完成为止。`0` 关闭（缺省），必须非负 | 0（关闭） |
| `exec_fault_scan` | 执行故障演练命中周期（扫描尝试序号，从 1 起）；`0` 关闭演练（缺省） | 0（关闭） |
| `exec_fault_scan_end` | 演练命中窗口结束序号；`0` 表示只在 `exec_fault_scan` 单周期；否则取闭区间窗口内第一个到达周期 | 0 |
| `exec_fault_after_instructions` | 演练异常在命中周期执行完第几条指令后抛出（`0` 表示第一条指令执行前） | 0 |
| `retain` | 保持项地址名称数组，如 `["M0.0","MW0","C0"]` | 空（不保持） |
| `retain_file` | 保持数据文件本地路径；空表示禁用保持 | 空 |
| `safe_outputs` | 故障安全输出表：地址名 → 整数值（位取 0/1，字取整数）；未列出的输出故障时清 0 | 空表 |

约束（启动期强制）：

- JSON 不允许出现未知字段（`DisallowUnknownFields`），防止拼写错误被静默忽略。
- 保持项与安全输出必须是合法地址且在程序中真实引用，否则按 `IllegalAddress`/`ReferenceError` 拒绝。
- 安全输出只允许 `Q` 区地址。
- `watchdog_time_ms` 与 `watchdog_instructions` 是两道相互独立的单周期保护，
  缺省只启用条数保护；老配置文件不写新字段即完全保持旧行为。
- 演练参数仅用于本地故障演练：必须先给 `exec_fault_scan` 才能开启；
  `exec_fault_scan_end` 不得小于开始序号；`exec_fault_after_instructions` 不得超出程序指令边界数，
  否则按 `StructureError` 拒绝启动/热重载。

## 缺省与兼容

- 所有新增数值字段的缺省值都是 `0`，语义为“关闭/不启用”。
  老配置文件一个字不改即可加载；示例程序、演示命令、既有用例的逐拍行为与旧版本完全一致。
- 热重载时整份 `Config` 原子生效：新配置（含演练开关、墙钟上限）先在临时对象上完成全部校验，
  任一非法都整体拒绝并继续运行旧程序，不会出现“半套配置”。

## 输入脚本

`-script` 指向的文本文件逐行描述每个扫描周期的整包输入映像：

- 每行是若干十六进制字节（空白分隔），按顺序覆盖 `IB0, IB1, ...`，例如 `04` 表示 `I0.2=1`；
- `#` 开头为注释；行为空表示该拍不写入，保持上一拍输入。

脚本化输入 + 固定时间基，使每一次本地运行都可以逐拍复现。
