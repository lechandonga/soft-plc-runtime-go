# 可配置项（本地 JSON）

示例：`testdata/programs/config.json`

| 字段 | 含义 | 默认 |
| --- | --- | --- |
| `scan_period_ms` | 扫描周期标称时长（毫秒），同时是定时器确定时间基，必须为正 | 10 |
| `watchdog_instructions` | 单周期指令条数预算，超限进入 `WatchdogFault` | 100000 |
| `scan_time_limit_ms` | 单周期墙钟耗时上限（毫秒）：从输入采样到输出提交完成的总耗时超限进入 `ScanTimeoutFault`；`0` 表示关闭 | 0（关闭） |
| `fault_injection` | 本地故障演练配置（对象，见下）；缺省/`null` 表示关闭 | 关闭 |
| `retain` | 保持项地址名称数组，如 `["M0.0","MW0","C0"]` | 空（不保持） |
| `retain_file` | 保持数据文件本地路径；空表示禁用保持 | 空 |
| `safe_outputs` | 故障安全输出表：地址名 → 整数值（位取 0/1，字取整数）；未列出的输出故障时清 0 | 空表 |

## 兼容关系

- 老配置文件不写 `scan_time_limit_ms` / `fault_injection` 也能照原样加载：
  墙钟上限缺省为 `0`（关闭），演练缺省关闭，行为与引入这两项之前完全一致。
- `scan_time_limit_ms` 只接受 `>= 0`；负数按 `StructureError` 拒绝（冷启动与热重载口径一致）。
- 两个新配置项都走既有热重载路径：随整份配置在扫描周期边界原子切换，不存在“半套配置”。

## 本地故障演练（`fault_injection`，仅本地演练用）

```json
"fault_injection": { "exec_error_scans": [3], "at_instruction": 2 }
```

- `exec_error_scans`：注入异常的扫描周期号列表（1 起计，按运行时扫描计数）。
- `at_instruction`：注入点指令序号（0 起），执行到该指令前抛出运行期异常。
- 每个周期号在一次运行生命期内至多触发一次：故障周期不计数，显式恢复后重跑同一周期号不再重复注入。
- 注入点必须落在程序指令范围内、周期号必须 >= 1，否则启动/重载按 `StructureError` 拒绝。
- 关闭（缺省）时对正常运行的语义、确定性与并发安全零影响。

约束（启动期强制）：

- JSON 不允许出现未知字段（`DisallowUnknownFields`），防止拼写错误被静默忽略。
- 保持项与安全输出必须是合法地址且在程序中真实引用，否则按 `IllegalAddress`/`ReferenceError` 拒绝。
- 安全输出只允许 `Q` 区地址。

## 输入脚本

`-script` 指向的文本文件逐行描述每个扫描周期的整包输入映像：

- 每行是若干十六进制字节（空白分隔），按顺序覆盖 `IB0, IB1, ...`，例如 `04` 表示 `I0.2=1`；
- `#` 开头为注释；行为空表示该拍不写入，保持上一拍输入。

脚本化输入 + 固定时间基，使每一次本地运行都可以逐拍复现。
